Object Hierarchy

Nexacro follows a hierarchical object model:

nexacro.Application (Global)
├── Forms (Active/Loaded)
│   ├── Components (Button, TextInput, Grid, etc.)
│   │   ├── Properties (value, text, visible, etc.)
│   │   └── Events (onclick, onchange, etc.)
│   ├── Datasets
│   └── Variables
└── Transactions (Service Calls)

Button Component

this.Button00.text = "Click Me";
this.Button00.enabled = true;
this.Button00.click();

this.Button00_onclick = function(obj:Button, e:ClickEventInfo) {
    trace("Button clicked");
};

TextInput / Edit Component

this.edtOrderID.value = "ORD001";
this.edtOrderID.readonly = false;
this.edtOrderID.maxlength = 20;
this.edtOrderID.setFocus();

this.edtOrderID_onchange = function(obj:Edit, e:ChangeEventInfo) {
    trace("Value changed to: " + obj.value);
};

this.edtOrderID_onkeydown = function(obj:Edit, e:KeyEventInfo) {
    if (e.keycode == 13) {  // Enter
        this.search();
    }
};

Combo / Dropdown Component

this.cboStatus.addItem("Active", "ACTIVE");
this.cboStatus.setIndex(0);
this.cboStatus.value;  // Get selected value

this.cboStatus_onitemchanged = function(obj:Combo, e:ItemChangeEventInfo) {
    trace("Selected: " + e.value);
};

Grid Component

this.grdOrderList.selectAll();

CheckBox Component

this.chkActive.checked;  // Read-only value

this.chkActive_onchanged = function(obj:CheckBox, e:ChangeEventInfo) {

Radio / RadioButton Component

this.radMale.value = "M";
this.radMale.selected;  // Is this radio selected?

this.radMale_onchanged = function(obj:Radio, e:ChangeEventInfo) {

Event System & Handlers

Event Handler Pattern

componentName_eventName = function(obj:ComponentType, e:EventInfoType) {
    // obj = Component reference
    // e = Event details
};

// Examples
this.Button00_onclick = function(obj:Button, e:ClickEventInfo) { };
this.edtOrderID_onchange = function(obj:Edit, e:ChangeEventInfo) { };
this.grdOrderList_oncelldblclick = function(obj:Grid, e:CellClickEventInfo) { };

Common Event Info Properties

Property Type Description
e.keycode Number 13=Enter, 27=Escape, 32=Space
e.ctrlKey Boolean Ctrl key pressed?
e.value String/Number New value (change events)
e.postvalue String/Number Previous value
e.row Number Grid row index
e.col Number Grid column index
⚠️ Warning: Return false from event handler to prevent default behavior.

Data Binding & Datasets

Dataset Operations

// Row count
var count = this.dsOrderList.getRowCount();

// Add row
var nRow = this.dsOrderList.addRow();

// Set/get values
this.dsOrderList.setColumn(nRow, "orderID", "ORD001");
var value = this.dsOrderList.getColumn(nRow, "orderID");

// Row as object
var rowObj = this.dsOrderList.getRowObject(nRow);
this.dsOrderList.setRowObject(nRow, {orderID: "ORD002", amount: 2000});

// Clear data
this.dsOrderList.clearData();
this.dsOrderList.deleteRow(nRow);

Data Filtering & Search

// Find row
var nRow = this.dsOrderList.findRowExpr("orderID == 'ORD001'");

// Filter
this.dsOrderList.filter("amount > 1000");
this.dsOrderList.clearFilter();

// Sort
this.dsOrderList.sort("orderDate desc");
this.dsOrderList.sort("amount asc");

Service Transaction

this.transaction(
    "OrderSearch",      // Service ID
    "/api/orders",      // URL
    dsRequest,          // Input dataset
    dsResponse,         // Output dataset
    callback,           // Callback function
    "POST"              // HTTP method
);

function callback(strSvcId, nErrorCode, strErrorMsg) {
    if (nErrorCode == 0) {
        // Success: dsResponse has data
        trace("Rows: " + this.dsResponse.getRowCount());
    } else {
        trace("Error: " + strErrorMsg);
    }
}

Browser Agent Automation Patterns

Pattern 1: Button Click & Wait

// Playwright
await page.click('#Button_Search');
await page.waitForLoadState('networkidle');

// Or wait for specific condition
await page.waitForFunction(() => {
    var app = window.nexacro.getApplication();
    return app.mainForm.dsResults.getRowCount() > 0;
}, { timeout: 10000 });

Pattern 2: Fill Form & Submit

// Fill multiple fields
await page.fill('#edtOrderID', 'ORD001');
await page.fill('#edtCustomer', 'ACME Corp');

// Select dropdown
await page.click('#cboStatus');
await page.click('text=Completed');

// Check checkbox
await page.click('#chkActive');

// Submit
await page.click('#Button_Submit');
await page.waitForLoadState('networkidle');

Pattern 3: Extract Grid Data

const gridData = await page.evaluate(() => {
    const app = window.nexacro.getApplication();
    const ds = app.mainForm.dsOrderList;
    const rows = [];
    
    for (let i = 0; i < ds.getRowCount(); i++) {
        rows.push({
            orderID: ds.getColumn(i, 'orderID'),
            amount: ds.getColumn(i, 'amount'),
            status: ds.getColumn(i, 'status')
        });
    }
    return rows;
});

console.log(gridData);
💡 Tip: Always use evaluate() for complex data extraction to minimize round-trips.

Retry Strategies

async function retryClick(page, selector, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
        try {
            await page.click(selector, { timeout: 5000 });
            return;
        } catch (e) {
            console.log(`Retry ${i+1}: ${e.message}`);
            if (i === maxRetries - 1) throw e;
            await page.waitForTimeout(1000);
        }
    }
}

Best Practices & Tips

Wait Strategies

  • waitForLoadState('networkidle') - For API transactions
  • waitForSelector(selector) - For element appearance
  • waitForFunction(fn) - For custom conditions
  • waitForTimeout(ms) - Last resort delay

Common Pitfalls

Problem Solution
Element not found Verify ID; wait for form load; check for typos
Wrong value selected Use API method instead of clicking: setIndex()
Transaction hangs Add error callback; check network; increase timeout
Modal blocks action Add dialog handler: page.on('dialog', ...)
Dropdown options hidden Wait longer; try keyboard navigation
